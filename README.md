# Навигатор проектов

Каталог проектов Корпорации развития Республики Саха (Якутия) с публичной витриной, интерактивной картой и административной панелью.

## Запуск

1. Установите Node.js 20 или новее.
2. Установите зависимости: `npm install`.
3. Скопируйте `.env.example` в `.env.local` и задайте собственные `ADMIN_PASSWORD` и `JWT_SECRET`.
4. Запустите проект: `npm run dev`.
5. Откройте [http://localhost:3000](http://localhost:3000).

## Проверка

- `npm run lint` — проверка качества кода.
- `npm run build` — производственная сборка.

## Данные и загрузки

Данные проектов хранятся в `data/projects.json`. Загруженные через административную панель файлы сохраняются локально в `public/uploads` и намеренно не попадают в Git. Для постоянного хранения на сервере эту папку следует подключить к внешнему файловому хранилищу.
